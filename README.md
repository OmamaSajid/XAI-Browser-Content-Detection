# XAI Browser Content Detection

> **Work in Progress:** This repository serves as a project overview and research portfolio reference. The source code, trained models, and detailed implementation are not included or intended for public release. This repository is maintained solely to document the project's objectives, scope, and research contributions.

## Overview

XAI Browser Content Detection is a research project focused on identifying AI-generated content across multiple modalities, including text, images, audio, and video. It integrates deep learning-based detection techniques with Explainable Artificial Intelligence (XAI) to provide interpretable insights into detection results.

The project is designed as a browser extension, enabling users to analyze digital content encountered online and better understand its potential authenticity.

## Key Components

- **Text Detection:** Transformer-based AI-generated text classification.
- **Image Detection:** Deep learning-based synthetic image identification.
- **Audio Detection:** Detection of AI-generated and synthetic speech.
- **Video Detection:** Identification of manipulated and AI-generated video content.
- **Explainable AI:** Interpretable insights into model predictions.
- **Browser Extension:** User-facing interface for accessible content analysis.
- **Backend API:** FastAPI-based integration of detection models and browser functionality.
